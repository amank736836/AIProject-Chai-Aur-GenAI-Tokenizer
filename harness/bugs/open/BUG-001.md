# BUG-001 — High-Severity Advisories in Development Tooling

- **Bug ID:** BUG-001
- **Title:** Development/build dependency tree has npm audit findings
- **Severity:** High advisory matches in development dependencies; no production-only findings in this run
- **Priority:** P2 — review the build/CI trust boundary; not a demonstrated production-runtime vulnerability
- **Feature:** FEAT-005 / build and dependency supply chain
- **Environment:** Linux sandbox; Node 22.22.3, npm 10.9.8; current session working tree audited 2026-10-11.
- **Preconditions:** Dependencies installed from the current `package-lock.json`.

## Steps to reproduce

1. Run `npm audit` (or `npm audit --json`).
2. Run `npm audit --omit=dev` to isolate runtime dependencies.

## Expected

No unreviewed high/critical advisories in the resolved dependency graph, or an owner-approved mitigation/exception documented for the affected environment.

## Actual

- Full dependency tree: **5 high**, 0 critical/moderate/low; `npm audit` exits 1.
- Production-only tree: **0 findings**; `npm audit --omit=dev` exits 0.
- Reported package names: `eslint-config-next` (direct development dependency), `@next/eslint-plugin-next`, `braces`, `fast-glob`, and `micromatch` (transitive development/build dependencies).
- npm's suggested automatic remedy downgrades `eslint-config-next` to 14.2.35, a major-version mismatch with this app's Next.js 16.4.0. That suggested downgrade was not applied.

**Reproducible:** YES; executed 2026-10-11. Advisory applicability/exploitability in a particular developer/CI environment has not been assessed.<br>
**Evidence:** [full audit JSON](../../evidence/logs/RUN-2026-002-npm-audit-full.json), [production-only audit JSON](../../evidence/logs/RUN-2026-002-npm-audit-production.json), [exit statuses](../../evidence/logs/RUN-2026-002-npm-audit-status.txt).

## Root cause

The resolved development dependency graph contains versions matching npm advisory ranges. npm's automatic fix candidate is incompatible with the application's Next.js major version; a compatible dependency-owner review is required.

## Fix

**Not applied.** No production dependencies are flagged in the current production-only audit. Do not apply npm's proposed ESLint-config downgrade blindly. Have the dependency owner identify a compatible patch/override or document a CI/build risk acceptance, then rerun lint, type-check, build, tests and both audit commands.

## Regression test

Re-run `npm audit` and `npm audit --omit=dev` after any dependency changes. Current status: full-tree audit FAIL (five high advisory matches); production-only audit PASS (zero findings).
