# BUG-001 — Resolved Dependency Tree Has npm Audit Findings

- **Bug ID:** BUG-001
- **Title:** Resolved dependency tree has npm audit findings
- **Severity:** Critical findings are present in the resolved tree (npm reports two critical overall; one in production-only audit)
- **Priority:** P1 — review before release
- **Feature:** FEAT-005 / build and dependency supply chain
- **Environment:** Linux sandbox; Node 22.22.3, npm 10.9.8; locked dependencies installed with `npm ci`; audited 2026-10-07.
- **Preconditions:** Clean install from current `package-lock.json`.

## Steps to reproduce

1. Run `npm ci`.
2. Run `npm audit`.
3. Run `npm audit --omit=dev` to isolate the production dependency tree.

## Expected

No unreviewed critical/high advisories in release dependencies; dependency owner has accepted or mitigated any remaining findings.

## Actual

- Full tree: **23** findings — 2 moderate, 19 high, 2 critical; npm exits 1.
- Production-only tree: **5** findings — 4 high, 1 critical; npm exits 1.
- `next` is a direct production dependency at 15.4.10 and is reported critical by the audit service. `tar` is a transitive critical finding in the full tree. Other findings include transitive `postcss`, `sharp`, `nanoid`, ESLint and TypeScript tooling packages.
- npm audit reported a non-breaking `next@15.5.27` fix candidate for the direct package at the audit date; that is an audit suggestion, not a validated upgrade.

**Reproducible:** YES (audit reproduced in this run). Advisory applicability/exploitability for a particular deployment has not been assessed.  
**Evidence:** [`RUN-2026-001-npm-audit.txt`](../../evidence/logs/RUN-2026-001-npm-audit.txt), [`RUN-2026-001-npm-audit-full.json`](../../evidence/logs/RUN-2026-001-npm-audit-full.json), [`RUN-2026-001-npm-audit-production.json`](../../evidence/logs/RUN-2026-001-npm-audit-production.json).

## Root cause

The lockfile resolves dependency versions that match current npm advisory ranges. No dependency-update/security review policy or automated CI audit is present in the repository.

## Fix

**Not applied.** Dependency upgrades can affect Next.js, ESLint and the build; they are outside this harness-only request. Have the dependency owner review compatible updates, run the complete suite/build/audit, and review applicable advisories before release.

## Regression test

Re-run both audit commands after dependency changes and record counts/advisory references. Current result: FAIL. See SCN-701 and release readiness report.

- **Status:** OPEN
