# AI-Assisted Testing

This folder gives future agents controlled project-specific instructions for testing without fabricating behavior or results.

- [`test-agent-instructions.md`](test-agent-instructions.md) — mandatory workflow, repository map, run/record/verify/report process.
- [`test-prompts.md`](test-prompts.md) — reusable prompts for test planning, case generation, execution review and bug triage.
- [`test-generation-rules.md`](test-generation-rules.md) — ID, evidence, privacy and scope rules.

Always follow **Analyze → Plan → Test → Record → Verify → Report**. Preserve all `NOT_EXECUTED` statuses unless the tests are actually run.
