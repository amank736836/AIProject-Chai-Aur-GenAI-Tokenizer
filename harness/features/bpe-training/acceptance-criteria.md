# FEAT-001 Acceptance Criteria

These checkboxes describe expected criteria, not release sign-off; execution status is recorded in the linked test cases.

Observed, code-derived criteria (not formal product approval):

- [ ] Base vocabulary contains expected special IDs and 100 standard slots before added corpus characters (TC-001).
- [ ] A merge step reports the most frequent pair and changes vocabulary/corpus consistently (TC-002).
- [ ] Requested target below base is clamped; an exhausted corpus terminates without hanging (TC-004).
- [ ] Full and stepped training produce equivalent learned records for the same input (TC-007).
- [ ] In a browser, preset selection, text editing, speed, pause and instant training work with clear status (TC-102; NOT_EXECUTED).
- [ ] Reduced-motion browser preference avoids animated training (TC-105; NOT_EXECUTED).
