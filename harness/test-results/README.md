# Test Results

Execution records are immutable snapshots. `latest/execution.md` summarizes the current run; `historical/RUN-*.md` retains dated records; `summaries/` links to cross-run reports. New runs receive a new RUN ID and must not overwrite historical evidence.

- Latest: [`latest/execution.md`](latest/execution.md)
- History: [`historical/RUN-2026-001.md`](historical/RUN-2026-001.md)
- Cross-run summary: [`summaries/README.md`](summaries/README.md)
- Raw logs: [`../evidence/logs/`](../evidence/README.md)
